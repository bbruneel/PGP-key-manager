# Customer cloud storage setup

Per-provider guides for BYO storage connections. Phase 17b ships **AWS S3** only; Azure and Google Cloud guides will be added in later phases.

| Provider | Guide |
|----------|-------|
| AWS S3 | [aws/setup.md](aws/setup.md) |

After deploying IAM/bucket access in your account, register the connection in **Settings → Cloud storage connections** and click **Test connection**.
